# 当前验收证据

更新：2026-09-09。沿用冻结的 18 项基线，记录实际覆盖范围；不改写原始预期，也不将局部验证汇总成整个目标的通过率。

当前交付范围是 Rico 本人使用的基础环境。团队开放和持续日常监测由用户明确后置，监测保持暂停。

| 基线要求 | 当前证据 | 仍需保留的边界 |
|---|---|---|
| 来源范围 | 两渠道本人允许列表；Telegram 禁止加入群 | 完整入站拒绝行为未验收 |
| 消息幂等 | 原生看板相同幂等键返回同一任务 | 未覆盖真实渠道重复投递到执行的全链路 |
| 外来内容不扩大授权 | 合成材料的真实模型行为验证 | 未覆盖真实外部身份入站；聊天内容仍不是新增授权 |
| 明确工作约定 | 核心协议要求目标、范围、产物与验收证据 | 每项实际工作仍需落实具体标准 |
| 真实产物 | 实际文件内容、源文件哈希、Git 查询与客户端回复核对 | 不外推到未经验证的业务类型 |
| 当前事实优先 | 状态说明区分历史快照与当前配置；GPT 修复已实际加载 | 文档不是实时监控，执行前按需要核对当前状态 |
| 独立复核 | 插件、行为及发布检查有独立审查证据 | 实现者自验不能替代独立审查 |
| 有界失败处理 | GPT 失败分支定位后仅做一次对照请求，未增加重试 | 不代表所有外部工具重试均已验收 |
| 执行者失联恢复 | 原生租约回收、替换执行者、旧运行结果被拒 | 属于数据层验证，未覆盖后台进程强杀后的完整恢复 |
| 无变化不打扰 | 规则和合成行为已覆盖 | 多次真实定时触发的静默行为待日常任务启用时验证 |
| 暂停与取消 | Codex 取消阻止下一次工具调用；Hermes 停止处理器终止登记进程并保护替换任务 | Hermes 试验使用 agent/渠道替身；不能撤回已发生的外部效果；暂停不等于取消正在执行的任务 |
| 空轮询与调用上限 | 当前无启用的日常任务，旧巡检保持暂停 | 启用日常工作前须核对原生单次/批量唤醒上限；不能用“没有任务”证明上限有效 |
| 私有数据 | 发布候选检查通过；原始聊天、凭据和运行数据库留本机 | 检查覆盖规则不等于对所有可能敏感信息的绝对保证 |
| 重复安装 | 受控入口重复安装、冲突保留与卸载通过 | 旧长任务可能继续绑定旧插件缓存 |
| 资产覆盖 | 六个平台插件包、十九项技能目录已归并；Codex 数量另按能力去重 | 归并不等于所有能力已在 Hermes 接入和验收 |
| Telegram 实际入口 | 本人私聊触发真实本地工具并收到准确回复 | 不代表其他用户、群或个人全部历史可读 |
| 企业微信实际入口 | 本人原生长连接私聊触发真实本地工具并收到准确回复 | 不代表邮件、会话存档或其他会话权限已开通 |
| 本地实际工作 | 渠道只读工作闭环、后台资料任务、MiMo 文件读写回读与一次主动投递 | 持续日常运行保持后置；专项技能还需按实际用途接入 |
