# 配置与治理

## 加载规则

1. 用户明确指定的事项级配置优先，否则使用 `assets/default-config.json`。
2. 覆盖配置必须是完整文件，不做含糊的深层合并。
3. 每次启动都运行 `scripts/validate_config.py`；校验结果与配置 SHA-256 放入事项记录。
4. 安全字段只能保持或收紧，不能通过事项级配置放宽。

## 强制安全项

- 本地处理和解析器隔离开启；远程 MCP、文档指令触发的 shell/子进程及默认委派关闭。
- 合同内容网络使用为 `deny`。
- 法源要求实时、一手、查询日期和证据字段齐全。
- 事项间上下文、长期记忆、向量/代码图谱索引、正文日志均关闭。
- 接受全部修订、清洁稿、外发、高风险定稿均有人类批准门。

`schema/config.schema.json` 用于通用 JSON Schema 工具；内置校验器另外检查域名白名单和语义不变量，因此没有第三方 JSON Schema 库也能失败关闭。

## 事项级保留

- 默认不创建临时文件；若本地渲染工具必须落盘，使用独立事项目录、权限最小化并在本次任务结束时清理。
- 解析输入必须位于用户主目录、外接卷或受保护的本地临时根，且不能放在 Skill 或 Python 运行时目录中，以免共享只读规则扩大事项范围。
- 只长期保留经批准的交付物、文件哈希、版本关系、审批人/时间、法源证据和不含正文的事件记录。
- 不在终端、异常堆栈或调试日志中打印合同正文、搜索词中的交易事实或个人信息。

## 允许扩展但默认关闭

- 本地 OCR、恶意文件扫描器、数字签名验证器；启用前要锁定版本、审查依赖和证明无网络回退。
- 内部 playbook；需要版本、所有者、批准日期、适用范围和例外有效期。
- 子 Agent；只允许用户逐事项授权，且输入必须去标识化并保留人工复核门。
