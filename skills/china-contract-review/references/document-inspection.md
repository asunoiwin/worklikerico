# 文档完整性与隔离检查

## DOCX

DOCX 是 ZIP 容器。预检不得解压到磁盘或执行任何内容，应检查：

- 核心部件、内容类型和关系文件是否存在；
- 正文、页眉页脚、脚注尾注、文本框等故事范围；
- `w:ins`、`w:del`、移动和格式属性变更；
- 批注定义与批注范围；
- `w:vanish`、`w:webHidden`、白色/极小文字等不可见风险；
- 字段代码、超链接、外部关系和 `altChunk`；
- OLE/嵌入对象、宏、ActiveX、自定义 XML和数字签名部件；
- 附件或图片引用是否缺失；
- ZIP 路径穿越、异常条目数、压缩炸弹迹象和重复条目。

修订标记不存在，只能说明当前包内未发现标准标记，不能证明正文从未被直接修改。版本比较必须依赖已确认的基准文件。

## PDF

检查：

- 真实 PDF 文件头、文件大小、页数和加密状态；
- JavaScript、OpenAction、Additional Actions、Launch/URI 动作；
- 文件附件、注释、表单和签名字段；
- 元数据、低文本页/扫描页比例和提取失败；
- 超大页数或解析错误。

文本提取不代表视觉完整性。表格、盖章、手写签名、删除线、侧边批注、扫描附件和覆盖文字必须本地渲染后逐页核对。数字签名字段存在不等于签名有效；有效性需要独立、可信的本地验证器。

## 失败关闭

- 文件加密、损坏、类型伪装或超过限制：停止自动分析。
- 解析器缺失：报告 `partial`，不上传、不自动安装、不切换远程服务。
- 宏、OLE、外部关系或主动动作：只报告，不点击、不打开、不执行。
- 附件缺失或引用断裂：相关结论标为不完整。
