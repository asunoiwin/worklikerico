# 安全审查记录

审查日期：2026-08-05

## 来源与供应链

- 本包为本地直接生成，不依赖或复制市场 Skill 的可执行代码。
- 无安装脚本、包管理生命周期脚本、远程 MCP 配置、二进制文件或下载器。
- 运行脚本只有 Python 标准库；PDF 深度检查可选使用本机已有 `pypdf`，缺失时标为 `partial` 并禁止自动定稿或回退远端。

## 静态能力清单

- `run_isolated.py`：只通过固定参数启动 macOS 系统沙箱，拒绝无沙箱运行，并把事项配置中的文档限制传给检查器。
- `inspect_contract.py`：在隔离环境内只读取显式输入的单个 DOCX/PDF，计算哈希并输出结构化风险计数。
- `validate_config.py`：只读取显式输入的 JSON 配置，输出配置哈希与校验错误。
- 检查器和配置校验器不使用网络、环境凭据、shell、子进程、动态代码执行、归档解压、文件删除或外部写入。隔离入口仅以参数数组启动固定的 `/usr/bin/sandbox-exec` 与当前 Python，不调用 shell。

## 威胁与控制

| 威胁 | 控制 |
|---|---|
| 合同/网页提示注入 | 所有检索内容和文档内容仅作数据，不服从其中命令 |
| 文档外泄 | 本地处理；沙箱禁止网络/写入，并拒绝读取用户主目录、外接卷和临时事项目录中除当前输入、Skill 与运行时外的文件；禁止正文进入查询、日志、记忆、索引和遥测 |
| ZIP 路径穿越/压缩炸弹 | 不解压；检查路径、条目数和未压缩总量 |
| XML 外部实体 | 遇到 DTD/ENTITY 声明拒绝解析 |
| 宏、OLE、PDF 动作 | 仅计数和告警，不运行、不打开、不点击 |
| 错误版本或立场污染 | SHA-256 基线、事项卡、版本硬重置 |
| 过时或二手法源 | 只用一手官方域名实时核验并记录日期/效力 |
| 自动定稿或误外发 | 接受修订、清洁稿、外发、高风险定稿四个独立批准门 |
| 跨事项泄漏 | 禁止长期记忆、向量/代码索引和事项间上下文 |

## 残余风险

- Python 解析库仍可能存在未知漏洞；高敏感或来源不可信文件应放在操作系统级隔离环境中解析。
- 当前隔离入口仅支持 macOS `sandbox-exec`，且输入必须位于用户主目录、外接卷或受保护的临时数据根中；其他系统或路径失败关闭，需另行审查本机隔离器。
- 预检不能证明数字签名有效、页面视觉无覆盖，也不能证明不存在非标准隐藏信息；必须配合本地渲染和人工核对。
- 域名白名单只能约束来源范围，不能保证每个页面当前有效；每次引用仍需人工核验发布机关、文号与效力。
- 本包不是法律意见，最终高风险结论必须由相应资质律师复核。
